Troubleshooting

Problem Fix
requires cloth-config2 Install Cloth Config for your Minecraft version.
requires modmenu Install Mod Menu for your Minecraft version.
incompatible with cinematiczoom Keep only one Cinematic Zoom jar in mods.
Crash on launch Check Java: 17, 21 or 25, depending on Minecraft.
Settings screen missing Install both Mod Menu and Cloth Config.
Zoom key does nothing Bind Cinematic Zoom under Controls.
Wheel doesn't zoom Enable Mouse wheel during zoom and hold the zoom key.
Bars don't appear Use the cinematic key and set the bar height above 0.
Broken config Delete config/cinematiczoom/config.json and relaunch.

Report issues with logs/latest.log and your Minecraft, mods and loader versions.

Limits

  • Only one Cinematic Zoom build can be installed, so the original can't run alongside it.
  • Other zoom mods may conflict with FOV handling. Don't run them together. Import their settings instead.
  • Sodium, Iris and shaders have no known conflicts, but aren't specifically tested.
  • Quilt is tested with the actual loader on every Fabric version. See the verification report.
  • Each Forge and NeoForge jar loads only on its exact Minecraft version.
  • OptiFine isn't supported.

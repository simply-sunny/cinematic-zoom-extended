Install

For Minecraft 1.20.1 to 26.3. Client-side only.

  1. Install Fabric Loader.
  2. Install Fabric API, Cloth Config and Mod Menu for your Minecraft version.
  3. Remove any other Cinematic Zoom build. Only one can be installed.
  4. Put the jar for your Minecraft version from {{stores}} in mods. {{coming}}

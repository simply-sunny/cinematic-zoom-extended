Aspect ratios

New installations default to accurate magnification up to 500× and independent Linear bar animation. The aspect list includes Auto, 2.39:1, 2.35:1, 2:1, 1.85:1, 16:9, 16:10, 4:3, and 1:1. Add custom ratios or remove and reorder entries to control cycling. Ratios wider than the window add top and bottom bars, and narrower ratios add side bars. This crops the composition with an overlay. It does not change Minecraft's viewport or projection aspect.

Left and right cycling works while cinematic zoom is active. Enable global cycling to select a profile outside zoom. The selection is saved. Entry, exit, and profile changes each have their own Instant, Linear, or Smooth mode and duration. Profile changes leave magnification unchanged. Regular zoom always clears bars.

Both settings screens expose the maximum magnification, wheel settings, custom ratios, and all profile options. The Forge built-in screen takes comma-separated ratios in cycling order and validates them when saving.

Config file

Settings are saved to config/cinematiczoom.json in your Minecraft folder:

OS Path
Windows %appdata%\.minecraft\config\cinematiczoom.json
macOS ~/Library/Application Support/minecraft/config/cinematiczoom.json
Linux ~/.minecraft/config/cinematiczoom.json

Existing configurations keep legacy FOV, percentage bars, and their saved zoom limits. Migration creates cinematiczoom.json.v1.bak. Invalid files get a separate backup, and a failed backup disables writes to preserve the original. Unknown settings survive saves. Delete the config to start with the new defaults.

Coming from another zoom mod

On first launch, with no cinematiczoom.json yet, Extended imports what it recognizes from:

  • Zoomify: config/zoomify.json
  • Ok Zoomer: config/ok_zoomer/config.toml or legacy okzoomer.json
  • Just Zoom: config/justzoom/config.json
  • Other zoom mods: any JSON or TOML file with zoom in its path, matched by key name.

WI Zoom and Logical Zoom keep no config. Delete cinematiczoom.json and relaunch to import again.

Migrating from Cinematic Zoom 1.3

Swap the cinematiczoom-*.jar for Extended and keep config/cinematiczoom.json. These keys carry over: startingZoom, baseZoomMultiplier, barsPercent, smoothMs, hideHudDuringZoom, enableCinematicCamera, toggleMode, minZoomMultiplier.

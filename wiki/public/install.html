Install

For Minecraft 1.20.1 to 26.3. Client-side only.

  1. Install Fabric Loader (or Quilt Loader), Fabric API, Cloth Config, and Mod Menu for your Minecraft version. Cloth Config and Mod Menu are required.
  2. Put the jar for your Minecraft version in mods.
  3. Remove any other Cinematic Zoom build. Only one can be installed.
